script-1: ONE-TIME INITIALIZATION

O9000 (OEE CONTROL MACRO)

(---------------- INITIALIZATION ----------------)

#600 = 0    (Total produced)

N100
(---------------- CYCLE START ----------------)
#650 = 0    (good parts)
#651 = 0    (incomplete execution)
#700 = #3001
M99
